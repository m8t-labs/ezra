# Getting help

Four destinations, depending on what you need.

| If you want to… | Go to |
|---|---|
| Propose a skill, fix Ezra's knowledge, or report an answer Ezra got wrong | [Issues on the Ezra project](https://github.com/m8t-labs/ezra/issues) |
| Ask a question, or talk through an idea before writing it up | [Discussions on the Ezra project](https://github.com/m8t-labs/ezra/discussions) |
| Run Ezra, install it, or ask about the platform underneath it | [m8t.run](https://m8t.run) |
| Report a security issue or a leaked secret | [Report privately](https://github.com/m8t-labs/ezra/security/advisories/new), or <security@m8t.run> — see [SECURITY.md](SECURITY.md) |

Every destination above is the **canonical Ezra project**, `m8t-labs/ezra`. If you are
reading this in a fork, these are pointers upstream, not your own support channels — see
[CONTRIBUTING.md](CONTRIBUTING.md) for what to change.

If you want to change something rather than ask about it, [CONTRIBUTING.md](CONTRIBUTING.md)
is the shorter path — most contributions here are one Markdown file.

[@orkeren21](https://github.com/orkeren21) and [@ilanbm](https://github.com/ilanbm) watch
issues and discussions on the canonical repository.
